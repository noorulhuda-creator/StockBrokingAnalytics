# Stock Broking Operations & Trading Analytics

## Project Overview

This portfolio project simulates the operations of a fictional Australian stock broking company, Apex Securities.

The project uses SQL Server, Excel and Power BI to analyse client accounts, stock orders, trade executions, trading turnover and brokerage revenue.

## Project Objectives

- Design a relational database for stock broking operations.
- Analyse trading activity and brokerage revenue using SQL.
- Develop Excel reports for operational analysis.
- Build interactive Power BI dashboards to visualise key performance indicators.
- Document business insights and technical work.

## Tools and Technologies

- SQL Server and SQL Server Management Studio (SSMS)
- Microsoft Excel (planned)
- Power BI (planned)
- GitHub for project documentation and version control

## Current Progress

- Designed five core database tables.
- Created sample trading records.
- Developed a SQL report for daily trading turnover and brokerage revenue.

## Data Source

This project uses fictional client and trading data created for educational and portfolio purposes. No confidential company or customer information is used.
